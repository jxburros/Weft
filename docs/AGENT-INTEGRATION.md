# Agent integration

Last verified against code: 2026-10-17.

The repository packages `skills/weft/SKILL.md`, `.claude-plugin/plugin.json` and
`.mcp.json`. Install dependencies with `npm ci`, start Weft, then launch your
plugin-aware Claude client with this checkout as its plugin directory (for
example `claude --plugin-dir /absolute/path/to/Weft`). Supply `WEFT_TOKEN` through
the client's environment; `WEFT_API_URL` defaults to `http://127.0.0.1:9222`.
The plugin launches the checked-out bridge with `node bin/weft.js mcp`.
Pin your checkout to a reviewed release/commit; this configuration does not
automatically download or run the latest build. Other MCP clients can use the
absolute-path configuration in README.md. Plugin installation in an external
Claude client has not been verified here; the bridge protocol is tested locally.

`src/guidance.js` is the guidance source. `guide.get` exposes the topic registry
through the shared command catalog, CLI and MCP (`weft_workspace` with action `guide.get`). The skill's
reference is generated by `node scripts/generate-guidance.js`; the documentation
test rejects stale generated text and unknown command references. Add guidance
to that registry instead of copying independently maintained authority rules
into tool descriptions.

```sh
weft guide.get '{"topic":"tab-control"}'
```

Documentation examples are schema-validated offline, not executed against your
browser. Their placeholder IDs require discovery in a running session. Eval
reference tasks exercise the MCP bridge and real workspace service with a
fixture browser; see `evals/README.md` for the boundaries of that evidence.

Agents can read update state with `update.status` (MCP `weft_browser`; also
allowed for scoped `read` clients). It reports the installed version, channel,
kill switch, staged update and health without contacting the network. Checking,
installing, rolling back and configuring updates are human-only; automation
receives `human_required` and should ask the person to use Settings > Updates.

```sh
weft update.status
```
