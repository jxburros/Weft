# Command reference

Generated by `node scripts/command-reference.js` from the shared catalog. Do not edit the table.

REST, CLI, MCP and GUI IPC use a version 1 outcome: `{schemaVersion, command, execution, validation, review, workspaceId, tabId, normalized, result, error}`. Execution is `succeeded`, `failed`, `cancelled`, or `not_started`; validation is `passed`, `failed`, or `not_run`. Review is `required` on authority denial and `not_required` otherwise; it never claims human approval. Null resource IDs mean no resource was resolved. The GUI preload and client.execute unwrap results for compatibility; executeOutcome exposes the full contract.

Errors include a stable code, message, field, schema lookup and, when relevant, allowed values, suggestions and a list of field issues. Invalid values are not echoed. CLI emits the entire outcome as JSON on stdout, including failures: exit 0 success; 2 invalid input/unknown command/ambiguous target; 3 stale state/lease conflict; 4 authority denial; 5 unsupported capability (for example image input or a context window the selected model lacks; details name the capability); 6 cancellation/emergency stop; 7 timeout/unavailable/transport failure; 1 other failure. REST uses 400 invalid input, 403 denial, 404 missing target, 409 conflict/cancellation, 422 unsupported capability or other command failure, 503 unavailable, 504 timeout. A transport timeout does not prove a remote action failed; inspect state before retrying consequential work.

Normalization rewrites `tabs.open` to `tabs.new`, recognized top-level snake_case fields to camelCase, and `href` to `url` only for tabs.new/page.navigate. Every rewrite appears in `normalized: [{from,to}]`. Conflicting aliases are rejected; values, unknown fields and nested free-form data are never coerced.

MCP advertises eight tools: weft_tabs, weft_page, weft_workspace, weft_records, weft_artifacts, weft_browser, weft_models and weft_reference. Grouped calls use `{action: "canonical.command", args: {...}}`; reference uses `{command: "canonical.command"}` or no arguments for an index. Existing underscore command tool calls remain accepted but are not advertised. Results include structuredContent and the same JSON text envelope; screenshots also include native image content. Mixed read/write groups conservatively advertise destructive/read-only hints; the reference exposes exact per-command metadata.

Human-only describes an unconditional administration gate; other commands may still require approval or be refused by resource scope, autonomy, state or content policy. GUI controls expose a subset; trusted IPC can invoke every catalog command. Native window layout is a separate trusted IPC channel.
